# DESIGN.md

## 气质与意象
- **意象锚点**：精密仪器控制台 / 信号监视中心。产品定位为面向风控、运营人员的高密度管理后台，强调信息清晰、节奏沉稳、专业可信。
- 场景画面：一间安静的监控室，浅色仪表盘上流动着精确的数据信号线，规则节点之间是一条条清晰的"触发链路"。

## 视觉策略
- 浅色为主的高密度后台（非暗黑军事风），以精细的栅格、表格、分区卡片组织信息。
- 可视化规则画布是核心舞台：节点采用圆角矩形"芯片/仪表"质感，带分类色描边；连接线用平滑的贝塞尔曲线，配合节点类型着色，表达"信号流"。
- 强调状态语义化：正常（中性）、待触发（琥珀）、已触发（红）、已完成（绿）。

## 配色方案
- 主色（品牌/交互）：墨蓝色 `#2563EB` 系（靛蓝调，避免荧光科技蓝）。
- 背景/表面：温润近白 `#F7F8FA`，卡片纯白 `#FFFFFF`，边框 `#E5E7EB`。
- 节点分类色（可用性导向）：
  - 数据源：蓝 `#3B82F6`
  - 条件（如果/且/或）：紫 `#8B5CF6`
  - 计算/关联：青 `#06B6D4`
  - 动作/预警：琥珀 `#F59E0B`
  - 时间/调度：绿（排除法与优先级用）：琥珀用于"预警动作"，绿用于"调度时间" `#10B981`
- 语义色：danger 红 `#EF4444`、success 绿 `#10B981`、warning 琥珀 `#F59E0B`。

## 字体排版
- 字体族：系统字体栈（PingFang SC / Microsoft YaHei / 思源黑体方向），数字与代码用等宽字体 `tabular-nums` 对齐。
- 排版节奏：标题用 500-600 字重、紧凑字距；数据表格 13px，正文 14px；标签用 12px。层级靠字重与间隔区分，减少彩色背景堆叠。

## 动效与交互
- 画布连线采用平滑贝塞尔 + 简短弹性过渡，拖拽节点有轻微缩放反馈与对齐吸附。
- 面板切换、抽屉、弹窗使用短促缓入（200-250ms ease-out），按钮 hover 有轻微明度提升。
- 连接、创建节点后高亮闪烁一次以引导视觉。

## 设计禁忌
- 禁止"科技蓝 + 紫渐变 + 圆角卡片"的模板化万能长相。
- 禁止暗黑军事风（黑色 + 荧光绿/红的高锐度告警墙）。
- 禁止大面积高饱和撞色背景；预警动作色只用在小面积签名元素上。
- 禁止无意义的粒子/光圈装饰，保持工具类产品的克制与精确。
